Fase 1 — Introducción a la Ciberseguridad

Criptografía Esencial — Cómo se protege la información

La criptografía es el arte de proteger información transformándola en algo ilegible para quien no tenga la clave. Es la base de HTTPS, las VPNs, las contraseñas, las firmas digitales y prácticamente toda la seguridad digital moderna. En esta lección entenderás cómo funciona el cifrado, qué son los hashes, cómo verificar la integridad de archivos y practicarás con GPG y OpenSSL.

1. ¿Qué es la criptografía?

La criptografía transforma datos legibles (texto plano) en datos ilegibles (texto cifrado) usando un algoritmo y una clave. Solo quien tenga la clave correcta puede descifrar y leer los datos originales.

Concepto básico
Texto plano  ──[Cifrado + Clave]──▶  Texto cifrado
"Hola mundo"  ──[AES-256 + clave]──▶  "x7f2$kL9..."

Texto cifrado  ──[Descifrado + Clave]──▶  Texto plano
"x7f2$kL9..."  ──[AES-256 + clave]──▶  "Hola mundo"

2. Cifrado simétrico: una clave para todo

En el cifrado simétrico, se usa la misma clave para cifrar y descifrar. Es rápido y eficiente, pero tiene un problema: ¿cómo le envías la clave a la otra persona de forma segura?

AlgoritmoTamaño de claveEstadoUso
AES-256256 bitsEstándar actualCifrado de discos (BitLocker), VPNs, HTTPS
AES-128128 bitsSeguroWiFi (WPA2), muchas aplicaciones
ChaCha20256 bitsModernoTLS 1.3, WireGuard VPN
DES56 bits❌ RotoYa no se debe usar — clave demasiado corta
3DES168 bits⚠️ ObsoletoSistemas legacy, siendo reemplazado
Cifrado simétrico con OpenSSL
# Cifrar un archivo con AES-256
$ openssl enc -aes-256-cbc -salt -in secreto.txt -out secreto.enc -pbkdf2
# Te pedirá una contraseña (esta será la clave simétrica)

# Descifrar
$ openssl enc -aes-256-cbc -d -in secreto.enc -out descifrado.txt -pbkdf2
# Te pedirá la misma contraseña

# Ver el archivo cifrado (es ilegible)
$ cat secreto.enc
# → Salida binaria incomprensible ✓

3. Cifrado asimétrico: la magia de las dos claves

El cifrado asimétrico usa dos claves que están matemáticamente relacionadas:

  • Clave pública: la puedes compartir con todo el mundo. Se usa para cifrar mensajes.
  • Clave privada: la mantienes en secreto. Es la ÚNICA que puede descifrar lo que se cifró con tu clave pública.

Analogía: El buzón con candado

Tu clave pública es como un buzón abierto en la calle: cualquiera puede meter una carta (cifrar un mensaje). Pero solo tú tienes la llave (clave privada) para abrir el buzón y leer las cartas. Aunque todos pueden meter cartas, nadie más puede leerlas.

AlgoritmoTamaño claveUso
RSA2048-4096 bitsHTTPS, SSH, firmas digitales, GPG
ECC (Elliptic Curve)256-384 bitsTLS 1.3, SSH moderno, criptomonedas
Ed25519256 bitsSSH keys modernas, firmas rápidas

4. Funciones hash: la huella digital de los datos

Un hash es una función que toma cualquier cantidad de datos y produce una cadena de tamaño fijo. Es una "huella digital" del dato original: si cambias un solo bit, el hash cambia completamente.

Propiedades de un buen hash

  • Determinista: el mismo input siempre produce el mismo hash.
  • Unidireccional: no puedes obtener el dato original a partir del hash.
  • Efecto avalancha: un cambio mínimo en el input cambia todo el hash.
  • Resistente a colisiones: es casi imposible encontrar dos inputs diferentes con el mismo hash.
Hashes en la práctica
# Generar hashes con diferentes algoritmos
$ echo -n "password123" | md5sum
482c811da5d5b4bc6d497ffa98491e38

$ echo -n "password123" | sha256sum
ef92b778bafe771e89245b89ecbc08a44a4e166c06659911881f383d4473e94f

# Efecto avalancha: cambiar una letra cambia TODO el hash
$ echo -n "password124" | md5sum
35ac04d1a8f319f2fd38d12e7ecd8b99  ← ¡Completamente diferente!

# Verificar la integridad de un archivo descargado
$ sha256sum kali-linux-2026.1.iso
a1b2c3d4...  kali-linux-2026.1.iso
# Compara este hash con el publicado en la web oficial

En ciberseguridad: las contraseñas no se guardan en texto plano — se guardan como hashes en /etc/shadow. Cuando haces login, el sistema hashea tu contraseña y la compara con el hash guardado. El cracking de contraseñas (Lección 12) consiste en generar millones de hashes y buscar coincidencias.

SHA-1160 bits❌ RotoObsoleto, no usar para nada nuevo

5. Firmas digitales y certificados

Una firma digital es la combinación de hash + cifrado asimétrico para garantizar que un mensaje es auténtico y no fue modificado. El emisor firma con su clave privada y cualquiera puede verificar con su clave pública. 

    FIRMAR:
    Documento ──[Hash]──▶ Hash ──[Cifrar con clave PRIVADA]──▶ Firma Digital

    VERIFICAR:
    Firma Digital ──[Descifrar con clave PÚBLICA]──▶ Hash Original
    Documento     ──[Hash]──▶ Hash Calculado
    
    ¿Hash Original == Hash Calculado?  →  Firma válida / ❌ Documento alterado

Certificados digitales (SSL/TLS)

Un certificado digital es un archivo que vincula una clave pública con la identidad de un servidor (ej: google.com). Es emitido por una Autoridad Certificadora (CA) de confianza (Let's Encrypt, DigiCert, etc.). Cuando visitas un sitio HTTPS, tu navegador verifica el certificado para asegurarse de que realmente estás hablando con ese servidor y no con un impostor.

6. TLS/SSL: cómo HTTPS protege tu navegación

TLS (Transport Layer Security) es el protocolo que hace posible HTTPS. Combina cifrado simétrico, asimétrico y hashes para crear una conexión segura:

  1. Handshake TLS: el servidor envía su certificado (con su clave pública).
  2. Tu navegador verifica el certificado con la CA.
  3. Se negocia una clave simétrica de sesión usando cifrado asimétrico (para velocidad).
  4. A partir de ahí, todo el tráfico se cifra con esa clave simétrica (AES-256 típicamente).

7. Práctica: GPG y OpenSSL

Ejercicio 1: Cifrado con GPG

GPG — Generar par de claves y cifrar
# Generar tu par de claves
$ gpg --full-generate-key
# Selecciona RSA, 4096 bits, y llena tus datos

# Ver tus claves
$ gpg --list-keys

# Exportar tu clave pública (para compartir)
$ gpg --export --armor tu@email.com > mi_clave_publica.asc

# Cifrar un archivo para ti mismo
$ gpg -e -r tu@email.com secreto.txt
# Genera: secreto.txt.gpg (cifrado)

# Descifrar
$ gpg -d secreto.txt.gpg > descifrado.txt

Ejercicio 2: Verificar integridad de archivos

Verificar hashes
# Crear un archivo y generar su hash
$ echo "Datos importantes" > datos.txt
$ sha256sum datos.txt > datos.sha256

# Verificar que no fue modificado
$ sha256sum -c datos.sha256
datos.txt: OK

# Modificar el archivo
$ echo "Modificado" >> datos.txt

# Verificar de nuevo
$ sha256sum -c datos.sha256
datos.txt: FAILED  ← ¡Detectó la modificación!
