Volatility 3 — Análisis forense de memoria RAM

La memoria RAM contiene tesoros de evidencia que no existen en el disco: procesos en ejecución, conexiones de red activas, contraseñas en claro, claves de cifrado y malware que solo vive en memoria. Volatility es la herramienta estándar de la industria para analizar dumps de RAM. En esta lección aprenderás a usar Volatility 3 paso a paso.

1. ¿Por qué analizar la RAM?

La RAM contiene evidencia que NO está en el disco:
  • Malware fileless: Código que solo existe en memoria, nunca toca el disco
  • Procesos en ejecución: Qué programas estaban corriendo al momento del incidente
  • Conexiones de red activas: A qué servidores C2 se estaba conectando el malware
  • Contraseñas en claro: Credenciales cacheadas por Windows (wdigest, Kerberos tickets)
  • Claves de cifrado: Si el disco está cifrado con BitLocker, la clave puede estar en RAM
  • Comandos ejecutados: Historial de cmd/PowerShell en memoria
  • Clipboard: Lo que se copió/pegó recientemente

2. Cómo capturar la RAM

HerramientaSOFormato
DumpItWindows.raw
WinPMEMWindows.raw / .aff4
FTK ImagerWindows.mem / .raw
LiMELinux.raw / .lime
osxpmemmacOS.raw
Captura de RAM
# Windows: DumpIt (ejecutar como Admin, solo doble clic)
C:\> DumpIt.exe /Q /O ram_dump.raw

# Windows: WinPMEM
C:\> winpmem_mini_x64.exe ram_dump.raw

# Linux: LiME (módulo de kernel)
$ sudo insmod lime.ko "path=/evidencia/ram.raw format=raw"

# SIEMPRE calcular hash inmediatamente
$ sha256sum ram_dump.raw > hash_ram.txt

3. Introducción a Volatility 3

Volatility 3 es la versión moderna del framework. Está escrito en Python 3 y tiene mejor rendimiento que Volatility 2.

Instalación y uso básico
# Instalar Volatility 3 (ya viene en Kali Linux)
$ pip3 install volatility3

# Sintaxis básica
$ vol -f ARCHIVO_RAM PLUGIN

# Ver todos los plugins disponibles
$ vol -f ram_dump.raw --help

# Volatility 3 detecta automáticamente el SO
# Los plugins se organizan por SO:
#   windows.pslist   → Listar procesos (Windows)
#   linux.pslist     → Listar procesos (Linux)

5. Analizar procesos

Análisis de procesos
# Listar todos los procesos
$ vol -f ram_dump.raw windows.pslist

PID   PPID  ImageFileName      CreateTime
4     0     System             2026-07-10 14:30:22
88    4     Registry           2026-07-10 14:30:18
384   4     smss.exe           2026-07-10 14:30:22
556   384   csrss.exe          2026-07-10 14:30:23
2340  1876  svchost.exe        2026-07-10 14:30:25
6712  2340  cmd.exe            2026-07-10 15:42:00  ← Sospechoso?

# Árbol de procesos (ver relaciones padre-hijo)
$ vol -f ram_dump.raw windows.pstree

# Buscar procesos OCULTOS (rootkits)
$ vol -f ram_dump.raw windows.psscan

# Si psscan muestra procesos que pslist NO muestra
# → Posible rootkit ocultando procesos

# Línea de comandos de cada proceso
$ vol -f ram_dump.raw windows.cmdline

PID 6712  cmd.exe  "C:\Windows\system32\cmd.exe" /c powershell -enc AEABRQ...
# ← PowerShell encoded! Muy sospechoso
🚩 Señales de alerta en procesos:
  • svchost.exe cuyo padre NO es services.exe
  • csrss.exe o lsass.exe con nombre ligeramente diferente (csrrs.exe, lssas.exe)
  • Procesos ejecutándose desde C:\Users\ o C:\Temp\
  • PowerShell con parámetro -enc (encoded command)
  • Procesos con timestamp mucho después que el resto

6. DLLs y handles

DLLs y handles
# Listar DLLs cargadas por un proceso específico
$ vol -f ram_dump.raw windows.dlllist --pid 6712

# Buscar handles (archivos, registros, mutex abiertos)
$ vol -f ram_dump.raw windows.handles --pid 6712

# Buscar un mutex específico (indicador de malware conocido)
$ vol -f ram_dump.raw windows.handles --pid 6712 | grep Mutant

7. Conexiones de red

Conexiones de red
# Ver todas las conexiones de red activas
$ vol -f ram_dump.raw windows.netscan

Offset     Proto  LocalAddr     LocalPort  ForeignAddr    ForeignPort  State       PID
0xe38f01   TCPv4  10.10.10.5    49832      185.99.2.3     443          ESTABLISHED 6712
0xe39a22   TCPv4  10.10.10.5    445        0.0.0.0        0            LISTENING   4

# PID 6712 conectado a 185.99.2.3:443 → ¿Servidor C2?
# Investigar esa IP en VirusTotal, AbuseIPDB, etc.

8. Registro de Windows en RAM

Registry en RAM
# Listar hives del registro en memoria
$ vol -f ram_dump.raw windows.registry.hivelist

# Buscar claves de persistencia (Run keys)
$ vol -f ram_dump.raw windows.registry.printkey --key "Software\Microsoft\Windows\CurrentVersion\Run"

# Extraer hashes SAM (contraseñas locales)
$ vol -f ram_dump.raw windows.hashdump

Administrator:500:aad3b435...:31d6cfe0d16ae931b73c59d7e0c089c0:::

9. Detectar malware e inyección de código

Detección de malware
# Detectar inyección de código en procesos
$ vol -f ram_dump.raw windows.malfind

PID   Process      Start VPN     Tag   Protection       Hexdump
6712  cmd.exe      0x1e0000       VadS  PAGE_EXECUTE_RW  4d 5a 90 00 ...

# 4d 5a = "MZ" → ¡Hay un ejecutable inyectado en cmd.exe!
# PAGE_EXECUTE_READWRITE → Memoria con permisos sospechosos

# Extraer el ejecutable inyectado
$ vol -f ram_dump.raw windows.malfind --dump --pid 6712

# Escanear con YARA rules
$ vol -f ram_dump.raw yarascan.YaraScan --yara-file reglas_malware.yar

10. Extraer archivos y strings

Extracción
# Listar archivos en memoria
$ vol -f ram_dump.raw windows.filescan | grep -i "sospechoso"

# Extraer un archivo específico por su offset
$ vol -f ram_dump.raw windows.dumpfiles --virtaddr 0xe38f01234

# Extraer el ejecutable de un proceso
$ vol -f ram_dump.raw windows.pslist --dump --pid 6712

# Buscar strings en la memoria de un proceso
$ strings -e l ram_dump.raw | grep "password"
$ strings -e l ram_dump.raw | grep "http://"

11. Crear un timeline

Timeline de eventos
# Crear timeline con todos los artefactos temporales
$ vol -f ram_dump.raw timeliner.Timeliner > timeline.csv

# Filtrar por rango de tiempo del incidente
$ grep "2026-07-10 15:4" timeline.csv

# Esto muestra todo lo que pasó entre 15:40 y 15:49
