Fase 4 — Informática Forense y DFIR

Autopsy — Análisis forense de discos duros

Autopsy es la plataforma forense de código abierto más utilizada en el mundo. Te permite cargar imágenes de disco, buscar archivos borrados, analizar metadatos, construir timelines de actividad, buscar palabras clave, extraer artefactos web y generar reportes completos. En esta lección aprenderás a usarla paso a paso para una investigación real.

1. ¿Qué es Autopsy?

Autopsy es una plataforma forense de código abierto construida sobre The Sleuth Kit (TSK). Proporciona una GUI para hacer análisis de discos que de otra forma requerirían muchos comandos de terminal.

CaracterísticaDescripción
Formatos soportadosE01, RAW/dd, VMDK, VHD, ISO, y más
Módulos de ingestProcesamiento automático: hash, keywords, artefactos web, EXIF, etc.
File carvingRecuperar archivos borrados por su firma (PhotoRec integrado)
TimelineVisualización cronológica de toda la actividad del disco
TaggingMarcar archivos como "notable", "sospechoso", "evidencia"
ReportesGenerar reportes HTML o CSV con hallazgos etiquetados

2. Instalación y requisitos

Instalación
# Windows: Descargar el instalador MSI desde autopsy.com
# Se instala con JDK incluido

# Linux (Kali): instalar via apt
$ sudo apt install autopsy

# Requisitos recomendados:
# - 16 GB RAM mínimo (para imágenes grandes)
# - SSD para almacenar el caso (mucho I/O)
# - Espacio libre: 2-3x el tamaño de la imagen

3. Crear un caso forense

Pasos para crear un caso:
  1. Abrir Autopsy → New Case
  2. Case Name: Nombre descriptivo (ej: "Caso-2026-001-Ransomware-Contabilidad")
  3. Base Directory: Dónde se almacenarán los archivos del caso
  4. Case Number: Número de referencia interno
  5. Examiner: Tu nombre completo (aparece en el reporte)
  6. Click Finish

Autopsy creará una estructura de directorios para el caso con subcarpetas para módulos, exportaciones y la base de datos SQLite del caso.

4. Cargar una imagen de disco

Agregar la evidencia:
  1. En el caso creado → Add Data Source
  2. Seleccionar tipo: Disk Image or VM File
  3. Navegar hasta tu imagen forense (.E01, .raw, .dd)
  4. Seleccionar Ingest Modules a ejecutar:
    • Hash Lookup — comparar archivos con NSRL (archivos conocidos buenos)
    • File Type Identification — identificar archivos por su firma
    • Recent Activity — extraer artefactos del sistema
    • Keyword Search — buscar términos configurados
    • Email Parser — extraer emails
    • Extension Mismatch Detector — archivo .jpg que realmente es .exe
    • PhotoRec Carver — recuperar archivos borrados
  5. Click Next → Autopsy comienza a procesar

5. Navegar el sistema de archivos

Una vez procesada la imagen, puedes navegar el sistema de archivos como si fuera un explorador:

Panel izquierdo — Árbol de navegación:
  • Data Sources: La imagen cargada y sus particiones
  • Views: Agrupación por tipo de archivo (imágenes, videos, documentos, ejecutables)
  • Results: Hallazgos de los módulos de ingest
  • Tags: Archivos que has etiquetado manualmente
Rutas importantes a revisar en Windows:
  • C:\Users\[usuario]\Desktop\ — Archivos en el escritorio
  • C:\Users\[usuario]\Downloads\ — Descargas recientes
  • C:\Users\[usuario]\AppData\ — Datos de aplicaciones
  • C:\Windows\Prefetch\ — Evidencia de ejecución de programas
  • C:\Windows\System32\config\ — Registry hives
  • C:\$Recycle.Bin\ — Papelera de reciclaje

6. Recuperar archivos borrados

Cuando borras un archivo, Windows solo marca el espacio como "disponible" pero los datos siguen ahí hasta que se sobreescriben. Autopsy puede recuperarlos de dos formas:

MétodoDescripciónDónde en Autopsy
File System AnalysisBuscar archivos marcados como borrados en la tabla MFT (NTFS)Archivos con ❌ rojo en el árbol de archivos
File CarvingBuscar firmas de archivos (JPG, PDF, DOCX) en espacio no asignadoViews → Deleted Files y Results → Carved Files

Para exportar un archivo recuperado: clic derecho → Extract File(s)

Autopsy extrae automáticamente artefactos forenses de Windows:

ArtefactoQué revelaUbicación

ShimcacheArchivos ejecutables que el sistema ha vistoRegistry: SYSTEM hive

8. Artefactos web

Autopsy extrae automáticamente el historial de navegación, descargas, cookies y bookmarks de los navegadores instalados:

En Results → Extracted Content:
  • Web History: URLs visitadas con timestamps
  • Web Downloads: Archivos descargados + URL de origen
  • Web Cookies: Cookies almacenadas por sitio
  • Web Bookmarks: Favoritos del usuario
  • Web Search: Términos buscados en Google, Bing, etc.

Esto es oro en una investigación: si alguien buscó "how to delete evidence" o "ransomware tutorial" justo antes del incidente, es evidencia directa de intención.

9. Búsqueda por palabras clave

Cómo buscar:
  1. Panel superior → Keyword Search
  2. Escribir término: "confidencial", "password", una dirección email
  3. Seleccionar tipo: Exact Match, Substring, o Regex
  4. Click Search
  5. Revisar resultados: muestra el archivo y el contexto donde aparece el término

También puedes crear listas de keywords personalizadas antes del ingest para buscar múltiples términos automáticamente (ej: lista de dominios C2 conocidos, nombres de empleados sospechosos).

10. Construir un timeline

El timeline es la herramienta más poderosa de un analista forense. Combina TODOS los timestamps (creación, modificación, acceso, eliminación) de todos los archivos en una vista cronológica.

En Autopsy:
  1. Menú → Timeline (o Tools → Timeline)
  2. Seleccionar rango de fechas del incidente
  3. Filtrar por tipo de evento (file created, file modified, web activity, etc.)
  4. Zoom al período de interés
  5. Buscar actividad anómala: creación masiva de archivos cifrados (ransomware), ejecución de herramientas de hacking, acceso a archivos sensibles

11. Hash analysis e identificación de malware

Comparación con NSRL y hash sets:
  • NSRL (National Software Reference Library): Base de datos de hashes de archivos conocidos legítimos (Windows, Office, etc.)
  • Archivos cuyos hashes coinciden con NSRL → Known good → los ignoras
  • Archivos cuyos hashes NO coinciden → Requieren investigación
  • Puedes importar tu propia lista de hashes de malware conocido para detectarlos automáticamente
  • Copiar el hash MD5/SHA-256 de un archivo sospechoso → buscarlo en VirusTotal

12. Generar el reporte forense

Generar reporte en Autopsy:
  1. Etiquetar todos los hallazgos relevantes con Tags (clic derecho → Add Tag)
  2. Menú → Generate Report
  3. Seleccionar formato: HTML (más completo) o CSV (para análisis adicional)
  4. Seleccionar qué incluir: Solo archivos etiquetados, o todo
  5. El reporte incluye: metadatos del caso, examiner, hash de la imagen, y todos los hallazgos con screenshots
