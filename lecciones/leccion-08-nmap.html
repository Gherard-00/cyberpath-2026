Fase 2 — Pentesting Fundamental

Nmap — Escaneo de redes y descubrimiento de servicios

Nmap (Network Mapper) es la herramienta más importante del pentester. Es lo primero que ejecutas al empezar un pentest: te dice qué hosts están vivos, qué puertos están abiertos, qué servicios y versiones corren, e incluso puede detectar el sistema operativo. En esta lección dominarás Nmap desde los fundamentos hasta técnicas avanzadas.

1. ¿Qué es Nmap y por qué es esencial?

Nmap es un escáner de red open source creado por Gordon "Fyodor" Lyon. Es la herramienta de reconocimiento más usada en el mundo por pentesters, administradores de red y equipos de seguridad.

Con Nmap puedes:

  • Descubrir hosts: encontrar qué dispositivos están activos en una red.
  • Escanear puertos: ver qué puertos están abiertos, cerrados o filtrados.
  • Detectar servicios: identificar qué software corre en cada puerto (Apache, SSH, MySQL...).
  • Detectar versiones: saber la versión exacta del servicio (útil para buscar exploits).
  • Detectar SO: adivinar qué sistema operativo tiene el objetivo.
  • Ejecutar scripts: lanzar scripts automatizados para detectar vulnerabilidades.

2. Descubrimiento de hosts: ¿quién está vivo?

Antes de escanear puertos, necesitas saber qué hosts están activos en la red. Nmap ofrece varias técnicas:

Descubrimiento de hosts
# Ping Sweep — descubrir hosts vivos en una red
$ nmap -sn 10.0.2.0/24
# -sn = solo descubrimiento, NO escanea puertos
# Resultado: lista de IPs que respondieron

# Escanear un rango específico
$ nmap -sn 10.0.2.1-50

# Escanear una lista de IPs desde un archivo
$ nmap -sn -iL targets.txt

# Descubrimiento con ARP (más efectivo en red local)
$ nmap -sn -PR 10.0.2.0/24

# Sin ping (útil si el host bloquea ICMP)
$ nmap -Pn 10.0.2.15
# -Pn = asume que el host está vivo, escanea directo

-sn es tu primer comando en cualquier pentest: te dice qué hay en la red sin hacer ruido excesivo. Si un host no responde a ping, usa -Pn para escanearlo de todas formas (muchos firewalls bloquean ICMP).

3. Tipos de escaneo de puertos

TipoFlagCómo funciona¿Cuándo usarlo?
SYN Scan (Half-open) -sS Envía SYN, si recibe SYN-ACK → abierto. Envía RST para no completar la conexión. Escaneo por defecto. Rápido, sigiloso. Necesita root.
TCP Connect -sT Completa el Three-Way Handshake completo. Cuando no tienes permisos de root. Más lento y detectable.
UDP Scan -sU Envía paquetes UDP. Si no hay respuesta, podría estar abierto o filtrado. Para servicios UDP (DNS:53, SNMP:161, DHCP:67). Muy lento.
FIN Scan -sF Envía paquete con flag FIN. Sistemas conformes a RFC responden con RST si cerrado. Evasión de firewalls básicos. No funciona contra Windows.
XMAS Scan -sX Envía paquete con flags FIN+PSH+URG activadas (como un árbol de navidad). Otra técnica de evasión de firewalls.
NULL Scan -sN Envía paquete TCP sin ninguna flag activada. Evasión de firewalls. No funciona contra Windows.
Escaneos de puertos en acción
# SYN Scan (el más usado) — necesita sudo
$ sudo nmap -sS 10.0.2.15

# Escanear puertos específicos
$ nmap -p 22,80,443,3306 10.0.2.15

# Escanear un rango de puertos
$ nmap -p 1-1000 10.0.2.15

# Escanear TODOS los puertos (65,535)
$ nmap -p- 10.0.2.15
# Puede tardar varios minutos

# Top 100 puertos más comunes (rápido)
$ nmap --top-ports 100 10.0.2.15

# Escaneo rápido de los 1000 puertos más comunes
$ nmap -F 10.0.2.15

¿Qué significan los estados de los puertos?

open — El puerto está abierto y un servicio está escuchando. Vector de ataque potencial.
closed — El puerto es accesible pero no hay servicio escuchando.
filtered — Un firewall está bloqueando el acceso. Nmap no puede determinar si está abierto o cerrado.
open|filtered — Nmap no puede distinguir entre abierto y filtrado (común en escaneos UDP).

4. Detección de servicios y versiones

Detección de servicios
# Detectar versiones de servicios (-sV)
$ nmap -sV 10.0.2.15

PORT     STATE SERVICE     VERSION
21/tcp   open  ftp         vsftpd 2.3.4
22/tcp   open  ssh         OpenSSH 4.7p1
80/tcp   open  http        Apache httpd 2.2.8 ((Ubuntu) DAV/2)
3306/tcp open  mysql       MySQL 5.0.51a-3ubuntu5

# Con más agresividad en la detección
$ nmap -sV --version-intensity 5 10.0.2.15

# Escaneo completo: puertos + versiones + scripts + SO
$ sudo nmap -sS -sV -sC -O 10.0.2.15
# -sS = SYN scan
# -sV = versiones
# -sC = scripts por defecto
# -O  = detección de SO

# Atajo para "escaneo agresivo" (equivalente a -sV -sC -O --traceroute)
$ sudo nmap -A 10.0.2.15

¿Por qué importan las versiones? Si descubres que un servidor tiene vsftpd 2.3.4, puedes buscar en Google o Exploit-DB si esa versión tiene vulnerabilidades conocidas. Spoiler: vsftpd 2.3.4 tiene un backdoor que permite acceso root. Lo explotarás con Metasploit en la Lección 11.

5. Detección de sistema operativo

Detección de SO
# Detección de sistema operativo (necesita root)
$ sudo nmap -O 10.0.2.15

OS details: Linux 2.6.9 - 2.6.33
Network Distance: 1 hop

# Con más agresividad
$ sudo nmap -O --osscan-guess 10.0.2.15

Nmap detecta el SO analizando las respuestas TCP/IP del objetivo (TTL, tamaño de ventana, opciones TCP). No es 100% exacto pero da una buena idea. Saber el SO te ayuda a elegir los exploits correctos.

6. Scripts NSE: el poder oculto de Nmap

NSE (Nmap Scripting Engine) es el sistema de scripts de Nmap. Contiene cientos de scripts para detectar vulnerabilidades, obtener información adicional y hasta explotar algunos fallos.

Scripts NSE
# Ejecutar scripts por defecto (safe + informational)
$ nmap -sC 10.0.2.15

# Ejecutar un script específico
$ nmap --script=http-title 10.0.2.15
# Muestra el título de la página web

# Buscar vulnerabilidades conocidas
$ nmap --script=vuln 10.0.2.15
# Ejecuta TODOS los scripts de detección de vulnerabilidades

# Scripts específicos útiles:
$ nmap --script=smb-vuln-ms17-010 10.0.2.15    # EternalBlue
$ nmap --script=ftp-anon 10.0.2.15              # FTP anónimo
$ nmap --script=ssh-brute 10.0.2.15             # Fuerza bruta SSH
$ nmap --script=http-enum 10.0.2.15             # Enumerar directorios web
$ nmap --script=mysql-info 10.0.2.15            # Info de MySQL
$ nmap --script=dns-zone-transfer -p 53 target  # Transferencia de zona DNS

# Ver todos los scripts disponibles
$ ls /usr/share/nmap/scripts/ | wc -l
# → 600+ scripts

# Buscar scripts por categoría
$ ls /usr/share/nmap/scripts/ | grep smb
$ ls /usr/share/nmap/scripts/ | grep http

7. Técnicas de evasión y timing

Timing y evasión
# Templates de velocidad (-T0 a -T5)
$ nmap -T0 10.0.2.15   # Paranoico — muy lento, difícil de detectar
$ nmap -T1 10.0.2.15   # Sneaky — lento
$ nmap -T2 10.0.2.15   # Polite — no sobrecarga la red
$ nmap -T3 10.0.2.15   # Normal (defecto)
$ nmap -T4 10.0.2.15   # Aggressive — rápido (el más usado)
$ nmap -T5 10.0.2.15   # Insane — muy rápido, puede perder puertos

# Fragmentar paquetes (evadir IDS/IPS)
$ nmap -f 10.0.2.15

# Usar un decoy (IP señuelo)
$ nmap -D RND:5 10.0.2.15
# Genera 5 IPs falsas para confundir al IDS

# Cambiar el puerto de origen
$ nmap --source-port 53 10.0.2.15
# Algunos firewalls permiten tráfico del puerto 53 (DNS)

8. Formatos de salida y reportes

Guardar resultados
# Guardar en formato normal (legible)
$ nmap -sV 10.0.2.15 -oN scan_normal.txt

# Guardar en formato XML (para parsear con herramientas)
$ nmap -sV 10.0.2.15 -oX scan.xml

# Guardar en formato grepable (para buscar con grep)
$ nmap -sV 10.0.2.15 -oG scan_grep.txt

# Guardar en TODOS los formatos a la vez
$ nmap -sV 10.0.2.15 -oA scan_completo
# Genera: scan_completo.nmap, scan_completo.xml, scan_completo.gnmap

Siempre guarda los resultados con -oA. Es tu evidencia para el reporte, y si necesitas consultar algo después, no tienes que volver a escanear.

Practica responsable

Todas las tecnicas de esta leccion deben practicarse exclusivamente en entornos autorizados: laboratorios locales, maquinas virtuales propias o plataformas como TryHackMe y HackTheBox. El acceso no autorizado a sistemas informaticos es un delito.

Ejercicio 1: Reconocimiento básico

Ejercicios con Metasploitable
