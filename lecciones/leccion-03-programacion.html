Python para Ciberseguridad — Programación orientada a hacking

Python es el lenguaje por excelencia en ciberseguridad. La mayoría de herramientas de pentesting tienen módulos en Python, los exploits se escriben en Python, la automatización de tareas se hace en Python. En esta lección aprenderás lo esencial de Python con enfoque directo en seguridad: variables, funciones, archivos, sockets, peticiones HTTP y cómo crear tus propias herramientas de hacking.

🐍 1. ¿Por qué Python en ciberseguridad?

Python es el lenguaje más usado en ciberseguridad por varias razones:

  • Es fácil de aprender: su sintaxis es limpia y legible, ideal para principiantes.
  • Tiene bibliotecas para todo: socket para redes, requests para HTTP, scapy para manipular paquetes, pwntools para exploits, paramiko para SSH.
  • Viene pre-instalado en Kali Linux y en la mayoría de servidores.
  • Los exploits se escriben en Python: Exploit-DB, Metasploit y muchas herramientas usan Python.
  • Automatización: puedes crear scripts para automatizar escaneos, analizar logs, generar reportes.

📐 2. Fundamentos: variables, tipos y operadores

fundamentos.py 
# Variables — No necesitas declarar el tipo
ip_objetivo = "10.0.2.15"         # string (texto)
puerto = 80                       # int (número entero)
es_vulnerable = True              # bool (verdadero/falso)
puntaje_cvss = 9.8                # float (decimal)

# f-strings: la forma moderna de incluir variables en texto
print(f"Objetivo: {ip_objetivo}:{puerto}")
print(f"¿Vulnerable? {es_vulnerable}")
print(f"CVSS: {puntaje_cvss}")

# Operadores
a = 10
b = 3
print(a + b)    # 13  — suma
print(a - b)    # 7   — resta
print(a * b)    # 30  — multiplicación
print(a / b)    # 3.33 — división
print(a // b)   # 3   — división entera
print(a % b)    # 1   — módulo (resto)
print(a ** b)   # 1000 — potencia

# Input del usuario
target = input("Introduce la IP objetivo: ")
print(f"Escaneando {target}...")

f-strings (format strings) son la forma más limpia de combinar variables con texto. Escribes f"texto {variable}" y Python sustituye {variable} por su valor.

while intentos < max_intentos:

Importante en Python: la indentación (espacios al inicio) NO es decorativa, es obligatoria. Python usa la indentación para saber qué código pertenece a cada bloque. Siempre usa 4 espacios.

🧩 4. Funciones: organiza tu código

Funciones en Python 
# Definir una función
def escanear_puerto(ip, puerto):
    """Verifica si un puerto está abierto."""
    import socket
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(1)
    resultado = sock.connect_ex((ip, puerto))
    sock.close()
    return resultado == 0  # True si está abierto

# Usar la función
ip = "10.0.2.15"
puertos = [21, 22, 80, 443, 445, 3306]

for puerto in puertos:
    if escanear_puerto(ip, puerto):
        print(f"✅ Puerto {puerto} ABIERTO")
    else:
        print(f"❌ Puerto {puerto} cerrado")

# Función con valor por defecto
def banner():
    print("=" * 50)
    print("  CyberPath — Port Scanner v1.0")
    print("=" * 50)

# Función que retorna un valor
def clasificar_puerto(puerto):
    servicios = {
        21: "FTP", 22: "SSH", 23: "Telnet",
        25: "SMTP", 53: "DNS", 80: "HTTP",
        443: "HTTPS", 445: "SMB", 3306: "MySQL",
        3389: "RDP"
    }
    return servicios.get(puerto, "Desconocido")

La función escanear_puerto() es un mini port scanner. Intenta conectarse a una IP y puerto; si lo logra (resultado 0), el puerto está abierto. Esta lógica es la base de cómo funciona Nmap internamente.

📝 5. Strings: manipulación de texto

En ciberseguridad trabajarás constantemente con texto: logs, hashes, URLs, IPs, respuestas HTTP. Saber manipular strings es fundamental.

Operaciones con strings 
# Métodos esenciales de strings
url = "  https://EJEMPLO.com/admin/login.php  "

print(url.strip())        # Quitar espacios: "https://EJEMPLO.com/admin/login.php"
print(url.lower())        # Minúsculas: "  https://ejemplo.com/admin/login.php  "
print(url.upper())        # Mayúsculas: "  HTTPS://EJEMPLO.COM/ADMIN/LOGIN.PHP  "
print(url.replace("http", "ftp"))  # Reemplazar texto

# Split: dividir un string en partes
log_line = "192.168.1.100 - - [09/Jul/2026:10:30:15] GET /admin HTTP/1.1 200"
partes = log_line.split(" ")
ip = partes[0]            # "192.168.1.100"
metodo = partes[5]        # "GET"
ruta = partes[6]          # "/admin"
codigo = partes[7]        # "200"

# Join: unir una lista en un string
palabras = ["admin", "password", "123456"]
linea = "\n".join(palabras)  # "admin\npassword\n123456"

# Slicing: extraer partes de un string
hash_md5 = "5d41402abc4b2a76b9719d911017c592"
print(hash_md5[:8])       # "5d41402a" — primeros 8 caracteres
print(hash_md5[-8:])      # "1017c592" — últimos 8 caracteres

# Verificar contenido
print("admin" in url)     # True
print(url.startswith("https"))  # False (tiene espacios al inicio)
print(url.strip().startswith("https"))  # True

💾 6. Lectura y escritura de archivos

Trabajar con archivos 
# === ESCRIBIR un archivo ===
with open("resultados.txt", "w") as f:
    f.write("Puerto 22: ABIERTO (SSH)\n")
    f.write("Puerto 80: ABIERTO (HTTP)\n")
    f.write("Puerto 443: CERRADO\n")

# === LEER un archivo completo ===
with open("resultados.txt", "r") as f:
    contenido = f.read()
    print(contenido)

# === LEER línea por línea (ideal para archivos grandes) ===
with open("/etc/passwd", "r") as f:
    for linea in f:
        if "/bin/bash" in linea:
            usuario = linea.split(":")[0]
            print(f"Usuario con bash: {usuario}")

# === AGREGAR contenido sin borrar (modo "a" = append) ===
with open("resultados.txt", "a") as f:
    f.write("Puerto 3306: ABIERTO (MySQL)\n")

# === Ejemplo real: cargar un diccionario de contraseñas ===
passwords = []
with open("wordlist.txt", "r") as f:
    for linea in f:
        passwords.append(linea.strip())

print(f"Diccionario cargado: {len(passwords)} contraseñas")

with open() es la forma correcta de trabajar con archivos en Python. Se asegura de cerrar el archivo automáticamente cuando terminas. Los modos son: "r" leer, "w" escribir (sobreescribe), "a" agregar al final.

🔌 9. Sockets: conexiones de red con Python

Un socket es un punto de comunicación entre dos máquinas a través de la red. Con sockets puedes crear tu propio port scanner, reverse shell, chat cifrado, o cualquier herramienta que se comunique por red.

port_scanner.py — Scanner de puertos 
import socket
from datetime import datetime

def scan_port(ip, port):
    """Intenta conectarse a un puerto. Retorna True si está abierto."""
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(1)
        result = sock.connect_ex((ip, port))
        sock.close()
        return result == 0
    except:
        return False

def banner_grab(ip, port):
    """Intenta obtener el banner del servicio."""
    try:
        sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        sock.settimeout(2)
        sock.connect((ip, port))
        sock.send(b"HEAD / HTTP/1.1\r\nHost: target\r\n\r\n")
        banner = sock.recv(1024).decode(errors="ignore").strip()
        sock.close()
        return banner[:100]  # Primeros 100 caracteres
    except:
        return "No banner"

# === Programa principal ===
target = input("IP objetivo: ")
print(f"\n🔍 Escaneando {target}...")
print(f"Inicio: {datetime.now()}\n")

puertos = [21, 22, 23, 25, 53, 80, 110, 443, 445, 993, 3306, 3389, 8080, 8443]

for port in puertos:
    if scan_port(target, port):
        banner = banner_grab(target, port)
        print(f"  ✅ Puerto {port:>5} ABIERTO  |  {banner[:60]}")

print(f"\n✅ Escaneo completado: {datetime.now()}")

¡Este es un port scanner funcional! Pruébalo contra tu máquina Metasploitable en el laboratorio. connect_ex() retorna 0 si la conexión fue exitosa (puerto abierto) o un código de error si no. banner_grab() intenta leer la respuesta del servicio para identificarlo.

# Verificar headers de seguridad de un sitio
def check_security_headers(url):
    """Verifica si un sitio tiene headers de seguridad configurados."""
    r = requests.get(url)
    headers_seguridad = [
        "X-Frame-Options",
        "X-Content-Type-Options",
        "Strict-Transport-Security",
        "Content-Security-Policy",
        "X-XSS-Protection"
    ]
    print(f"\n🔍 Headers de seguridad para {url}:\n")
    for header in headers_seguridad:
        valor = r.headers.get(header, "❌ NO CONFIGURADO")
        print(f"  {header}: {valor}")

check_security_headers("https://google.com")

🛠️ 11. Proyecto: tu primera herramienta de hacking

Vamos a combinar todo lo aprendido para crear un escáner de directorios web (similar a gobuster o dirb). Esta herramienta prueba rutas comunes en un servidor web para descubrir páginas ocultas.

dir_scanner.py — Escáner de directorios 
import requests
import sys
from datetime import datetime

def banner():
    print("=" * 55)
    print("  🔍 CyberPath Dir Scanner v1.0")
    print("  Escáner de directorios web")
    print("=" * 55)

def scan_directory(url, wordlist_path):
    """Escanea directorios de un servidor web usando un diccionario."""

    # Cargar el diccionario
    try:
        with open(wordlist_path, "r") as f:
            words = [line.strip() for line in f if line.strip()]
    except FileNotFoundError:
        print(f"❌ No se encontró el archivo: {wordlist_path}")
        return

    print(f"\n🎯 Objetivo: {url}")
    print(f"📖 Diccionario: {wordlist_path} ({len(words)} palabras)")
    print(f"⏰ Inicio: {datetime.now()}\n")

    encontrados = 0

    for i, word in enumerate(words):
        target_url = f"{url}/{word}"
        try:
            response = requests.get(target_url, timeout=3)

            # Mostrar progreso cada 50 peticiones
            if i % 50 == 0 and i > 0:
                print(f"  ... probando {i}/{len(words)}...")

            # Si el código no es 404, lo encontramos
            if response.status_code != 404:
                print(f"  ✅ [{response.status_code}] {target_url}")
                encontrados += 1

        except requests.exceptions.RequestException:
            pass  # Ignorar errores de conexión

    print(f"\n{'=' * 55}")
    print(f"  Escaneo completado: {encontrados} rutas encontradas")
    print(f"  Hora: {datetime.now()}")
    print(f"{'=' * 55}")

# === Programa principal ===
if __name__ == "__main__":
    banner()

    if len(sys.argv) != 3:
        print(f"\nUso: python3 {sys.argv[0]} <URL> <wordlist>")
        print(f"Ejemplo: python3 {sys.argv[0]} http://10.0.2.15 wordlist.txt")
        sys.exit(1)

    url = sys.argv[1].rstrip("/")
    wordlist = sys.argv[2]

    scan_directory(url, wordlist)

Para usarla:

1. Crea un archivo wordlist.txt con rutas comunes: admin, login, dashboard, uploads, backup, config, api, etc.

2. Ejecuta: python3 dir_scanner.py http://10.0.2.15 wordlist.txt

3. El escáner probará cada ruta y te mostrará las que existen (código diferente a 404).
