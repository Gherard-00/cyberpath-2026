Fase 4 — Blue Team y SOC

SIEM y Recolección de Logs

Un SOC sin visibilidad es ciego. Para detectar ataques, necesitas recolectar la telemetría (logs) de toda tu organización en un solo lugar. Ese lugar es el SIEM (Security Information and Event Management).

Contenido de esta lección

  1. ¿Qué es un SIEM?
  2. Splunk, ELK y Wazuh
  3. Sysmon y Windows Event Logs
  4. Normalización y Parsing

1. ¿Qué es un SIEM?

Un SIEM ingesta millones de logs generados por firewalls, servidores, antivirus y aplicaciones. Los analiza en tiempo real aplicando reglas de correlación y genera Alertas cuando detecta patrones sospechosos (ej. 5 intentos de login fallidos seguidos de 1 exitoso = posible fuerza bruta).

2. Soluciones SIEM del mercado

  • Splunk: El líder de la industria (comercial). Su lenguaje SPL es estándar para muchos analistas.
  • ELK Stack (Elasticsearch, Logstash, Kibana): Open source muy popular. Se usa a menudo con extensiones de seguridad (Elastic Security).
  • Wazuh: SIEM y EDR open source basado en ELK. Excelente para despliegues gratuitos con reglas preconfiguradas.
  • Microsoft Sentinel: SIEM nativo en la nube de Azure.

3. Sysmon y Visibilidad en Endpoints

Los logs por defecto de Windows (Event Viewer) son insuficientes para detectar atacantes avanzados. Los Blue Teams instalan Sysmon (System Monitor) de Sysinternals.

Sysmon enriquece enormemente la telemetría registrando eventos críticos con gran detalle:

  • Event ID 1: Creación de procesos (qué binario ejecutó a cuál, y con qué argumentos de línea de comandos).
  • Event ID 3: Conexiones de red (procesos haciendo conexiones hacia afuera).
  • Event ID 11: Creación de archivos (detecta malware escribiendo en disco).

4. Normalización y Parsing

Si un firewall Palo Alto llama a la IP de origen src_ip y un servidor Linux la llama SourceAddress, es imposible hacer búsquedas efectivas. El SIEM realiza el Parsing (extraer campos) y la Normalización (convertir todos los nombres a un esquema común, como Elastic Common Schema - ECS) para que una sola regla funcione para cualquier dispositivo.
