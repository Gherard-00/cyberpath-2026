Montar tu Laboratorio Virtual — Tu entorno de práctica seguro

No puedes aprender ciberseguridad sin practicar, y no puedes practicar en sistemas reales sin permiso. La solución: montar tu propio laboratorio virtual donde puedas atacar, defender y experimentar sin riesgo legal ni daño real. En esta lección instalarás VirtualBox, configurarás Kali Linux como tu máquina atacante, Metasploitable como objetivo vulnerable, y crearás una red virtual aislada donde todo está permitido.

1. ¿Por qué necesitas un laboratorio virtual?

Un laboratorio virtual es un entorno controlado donde ejecutas máquinas virtuales (VMs) en tu propia computadora. Cada VM es como una computadora separada corriendo dentro de tu PC.

  • Legal y seguro: todo ocurre dentro de tu computadora. No estás atacando sistemas reales de nadie.
  • Reversible: si rompes algo, puedes restaurar una snapshot y volver al estado anterior en segundos.
  • Realista: las VMs se comportan exactamente como máquinas reales, con sus propias IPs, servicios y vulnerabilidades.
  • Portátil: puedes llevar tu laboratorio a cualquier lugar en un USB o disco externo.

⚠️ IMPORTANTE: Legalidad

Solo puedes practicar hacking en sistemas que TÚ controlas o que tienes autorización escrita para probar. Atacar sistemas sin permiso es un delito en prácticamente todos los países. Tu laboratorio virtual es tu espacio seguro y legal para aprender.

¿Qué es la virtualización?

La virtualización te permite ejecutar un sistema operativo completo dentro de una ventana de tu computadora. El software de virtualización (VirtualBox, VMware) crea una "computadora virtual" con su propia CPU, RAM, disco y red — todo simulado usando los recursos de tu PC real. Para activarla, debes habilitar VT-x (Intel) o AMD-V (AMD) en la BIOS de tu computadora.

3. Instalar y configurar VirtualBox

VirtualBox es el software de virtualización que usaremos. Es gratuito, open source, y funciona en Windows, macOS y Linux.

Paso 1: Descargar VirtualBox

  1. Ve a https://www.virtualbox.org/wiki/Downloads
  2. Descarga la versión para tu sistema operativo (Windows hosts, macOS hosts, o Linux).
  3. También descarga el Extension Pack (misma página, sección "All supported platforms").

Paso 2: Instalar

  1. Ejecuta el instalador y sigue el asistente (acepta los valores por defecto).
  2. En Windows, te pedirá instalar drivers de red — acepta.
  3. Una vez instalado, abre VirtualBox.
  4. Ve a Archivo → Herramientas → Extension Pack Manager e instala el Extension Pack que descargaste.

Paso 3: Habilitar virtualización en BIOS

⚠️ Si VirtualBox da error al iniciar una VM

Probablemente necesitas habilitar la virtualización en la BIOS:
1. Reinicia tu PC y entra a la BIOS (presiona F2, DEL o F12 al arrancar — varía por marca).
2. Busca la opción Intel VT-x, Intel Virtualization Technology o AMD-V/SVM Mode.
3. Actívala (Enabled).
4. En Windows 11, además puede que necesites desactivar Hyper-V y Memory Integrity en la configuración de Windows.

4. Instalar Kali Linux

Kali Linux es la distribución de Linux diseñada para pentesting. Viene con +600 herramientas pre-instaladas. La forma más fácil de instalarla es descargar la imagen pre-construida para VirtualBox.

Opción rápida: imagen pre-construida (recomendada)

  1. Ve a https://www.kali.org/get-kali/#kali-virtual-machines
  2. Descarga la versión "VirtualBox (64-bit)" (archivo .7z o .ova).
  3. Si es .7z, descomprímelo con 7-Zip.
  4. En VirtualBox: Archivo → Importar servicio virtualizado → selecciona el archivo .ova.
  5. Revisa la configuración y haz clic en Importar.

Configuración recomendada

Ajustes de la VM de Kali 
Configuración → Sistema:
  RAM: 4096 MB (mínimo 2048 MB)
  Procesadores: 2 (mínimo 1)
  
Configuración → Pantalla:
  Memoria de video: 128 MB
  Habilitar aceleración 3D: ✓ (opcional)

Credenciales por defecto:
  Usuario: kali
  Contraseña: kali

5. Instalar Metasploitable 2

Metasploitable 2 es una máquina virtual intencionalmente vulnerable. Está diseñada para ser hackeada — tiene servicios mal configurados, contraseñas débiles, vulnerabilidades conocidas. Es tu objetivo de práctica principal.

Paso a paso

  1. Descarga Metasploitable 2 desde https://sourceforge.net/projects/metasploitable/
  2. Descomprime el archivo ZIP. Obtendrás archivos .vmdk (disco virtual).
  3. En VirtualBox:
    1. Clic en Nueva
    2. Nombre: Metasploitable2
    3. Tipo: Linux, Versión: Ubuntu (64-bit)
    4. RAM: 1024 MB (es suficiente)
    5. Disco duro: Usar un disco duro virtual existente → selecciona el archivo .vmdk
  4. Inicia la VM. El login es: msfadmin / msfadmin

⚠️ NUNCA expongas Metasploitable a Internet

Metasploitable tiene vulnerabilidades graves a propósito. Si la conectas a Internet, cualquier atacante real podría comprometerla en minutos. Solo debe estar en tu red virtual interna.

6. Configurar la red virtual aislada

Para que Kali pueda "atacar" a Metasploitable, ambas máquinas deben estar en la misma red virtual. La opción más segura es crear una red NAT o usar Red interna.

Opción 1: Red NAT (recomendada para principiantes)

Permite que las VMs se comuniquen entre sí Y tengan acceso a Internet (para actualizar software).

Crear la red NAT 
En VirtualBox:
1. Archivo → Herramientas → Administrador de red
2. Pestaña "Redes NAT" → Crear (+)
3. Nombre: CyberPathLab
4. CIDR: 10.0.2.0/24
5. Habilitar DHCP: ✓

Para cada VM (Kali y Metasploitable):
1. Selecciona la VM → Configuración → Red
2. Adaptador 1:
   - Conectado a: "Red NAT"
   - Nombre: CyberPathLab

Opción 2: Red interna (más aislada)

Las VMs solo se comunican entre sí, sin acceso a Internet. Más segura pero tendrás que configurar IPs manualmente.

Configurar Red Interna 
Para cada VM:
1. Configuración → Red → Adaptador 1
2. Conectado a: "Red interna"
3. Nombre: "pentest-lab"

Luego, en Kali, configura IP manualmente:
$ sudo ip addr add 10.0.2.5/24 dev eth0
$ sudo ip link set eth0 up

En Metasploitable:
$ sudo ifconfig eth0 10.0.2.15 netmask 255.255.255.0 up

8. Snapshots: tu red de seguridad

Las snapshots (instantáneas) guardan el estado completo de una VM en un momento dado. Si rompes algo, puedes restaurar la snapshot y volver al estado anterior en segundos. Son imprescindibles para practicar sin miedo.

Cómo usar Snapshots 
Crear una Snapshot:
1. Selecciona la VM en VirtualBox
2. Menú Máquina → Tomar Snapshot (Ctrl + Shift + S)
3. Dale un nombre descriptivo: "Kali - Estado Limpio"

Restaurar una Snapshot:
1. Selecciona la VM (debe estar apagada)
2. Haz clic en el icono de Snapshots (lista a la derecha)
3. Selecciona la snapshot → "Restaurar"

Snapshots recomendadas:
"Estado Limpio" — Justo después de instalar y actualizar
"Pre-Explotación" — Antes de un ejercicio de pentesting
"Laboratorio Funcional" — Cuando todo está configurado y verificado

Buena práctica

Antes de cada ejercicio de pentesting, toma una snapshot de tus VMs. Así, si algo sale mal (corrompes la VM, instalas malware por accidente, cambias configuraciones), puedes restaurar en 10 segundos en lugar de reinstalar todo desde cero.
