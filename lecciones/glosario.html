Glosario de Ciberseguridad

Definiciones claras de los conceptos clave del curso. Haz clic en una categoria para filtrar.

A
Active Directory (AD) Pentesting
Servicio de directorio de Microsoft que gestiona usuarios, equipos y politicas en redes Windows corporativas. Es uno de los objetivos principales en pentesting interno.
Ver: Leccion 13, Leccion 13A
ARP (Address Resolution Protocol) Redes
Protocolo que traduce direcciones IP a direcciones MAC en una red local. El ARP spoofing permite interceptar trafico en la misma red (ataque MitM).
Ver: Leccion 01
Autopsy Forense
Plataforma de analisis forense digital de codigo abierto. Permite examinar discos, recuperar archivos eliminados, analizar metadatos y crear timelines de actividad.
Ver: Leccion 18
B
Brute Force Pentesting
Tecnica que prueba todas las combinaciones posibles de contrasenas hasta encontrar la correcta. Herramientas como hydra y john automatizan este proceso.
Ver: Leccion 12
Burp Suite Web
Proxy de interceptacion y suite de herramientas para testing de seguridad web. Permite capturar, modificar y reenviar peticiones HTTP entre el navegador y el servidor.
Ver: Leccion 10
C
CIA Triad (Confidencialidad, Integridad, Disponibilidad) General
Los tres pilares fundamentales de la seguridad informatica. Toda medida de seguridad busca proteger al menos uno de estos principios.
Ver: Leccion 05
Cifrado asimetrico Criptografia
Sistema criptografico que usa un par de claves: una publica (para cifrar) y una privada (para descifrar). Ejemplos: RSA, ECC. Base de TLS/HTTPS y firmas digitales.
Ver: Leccion 06
CVE (Common Vulnerabilities and Exposures) General
Identificador unico global para vulnerabilidades de seguridad conocidas. Formato: CVE-YYYY-NNNNN. Se usa en informes de auditoria y bases de datos como NVD.
Ver: Leccion 20
CVSS (Common Vulnerability Scoring System) General
Sistema estandar para calificar la severidad de vulnerabilidades en una escala de 0 a 10. Considera vector de ataque, complejidad, privilegios requeridos e impacto.
Ver: Leccion 20
D
DNS (Domain Name System) Redes
Sistema que traduce nombres de dominio legibles (como google.com) a direcciones IP numericas. La enumeracion DNS es una de las primeras fases de reconocimiento.
Ver: Leccion 01
E
Exploit Pentesting
Codigo o tecnica que aprovecha una vulnerabilidad para obtener acceso no autorizado, escalar privilegios o ejecutar comandos en un sistema objetivo.
Ver: Leccion 11
F
Firewall Redes
Sistema que filtra trafico de red segun reglas predefinidas. Puede ser de red (hardware/software) o de host (como iptables en Linux o Windows Defender Firewall).
Ver: Leccion 05
Forensic Image (Imagen forense) Forense
Copia bit a bit de un dispositivo de almacenamiento que preserva toda la informacion, incluidos archivos eliminados y espacio no asignado. Se verifica con hash.
Ver: Leccion 16
H
Hash Criptografia
Funcion unidireccional que convierte datos de cualquier tamano en una cadena de longitud fija. Algoritmos comunes: MD5 (inseguro), SHA-256, bcrypt. Se usa para verificar integridad y almacenar contrasenas.
Ver: Leccion 06, Leccion 12
I
IDOR (Insecure Direct Object Reference) Web
Vulnerabilidad web donde un usuario puede acceder a recursos de otros usuarios manipulando identificadores en la URL o peticion (ej: /perfil?id=123 → id=124).
Ver: Leccion 09
K
Kerberoasting Pentesting
Tecnica de ataque contra Active Directory que solicita tickets de servicio Kerberos (TGS) para cuentas de servicio y los crackea offline para obtener contrasenas.
Ver: Leccion 13
M
Metasploit Pentesting
Framework de pentesting que incluye exploits, payloads, encoders y herramientas de post-explotacion. Su consola principal es msfconsole y su payload mas conocido es Meterpreter.
Ver: Leccion 11
MITRE ATT&CK General
Base de conocimiento que clasifica tacticas, tecnicas y procedimientos (TTP) usados por adversarios reales. Organizada en matrices por plataforma (Enterprise, Mobile, Cloud).
Ver: Leccion 15
N
Nmap Pentesting
Escaner de red y puertos. Identifica hosts activos, puertos abiertos, servicios en ejecucion y versiones. Ejemplo: nmap -sV -sC -p- target.
Ver: Leccion 08
O
OWASP Top 10 Web
Lista de las 10 vulnerabilidades web mas criticas, mantenida por la fundacion OWASP. Incluye inyeccion, autenticacion rota, XSS, SSRF, entre otras.
Ver: Leccion 09
P
Payload Pentesting
Codigo que se ejecuta en el sistema objetivo despues de explotar una vulnerabilidad. Puede ser una shell reversa, un meterpreter, o un comando simple.
Ver: Leccion 11
Pentesting (Prueba de penetracion) General
Simulacion autorizada de un ataque informatico para identificar vulnerabilidades en sistemas, redes o aplicaciones. Sigue metodologias como PTES o OWASP Testing Guide.
Ver: Leccion 07, Leccion 20
R
Reverse Shell Pentesting
Conexion donde el sistema comprometido inicia la comunicacion hacia el atacante, evitando restricciones de firewall. Es el tipo de shell mas comun en pentesting.
Ver: Leccion 11, Leccion 15
S
SQL Injection (SQLi) Web
Vulnerabilidad que permite inyectar consultas SQL maliciosas a traves de entradas de usuario no sanitizadas. Puede extraer, modificar o eliminar datos de la base de datos.
Ver: Leccion 09, Leccion 08B
SSRF (Server-Side Request Forgery) Web
Vulnerabilidad que permite hacer que el servidor realice peticiones HTTP a recursos internos. En cloud, se usa para acceder al servicio de metadata (169.254.169.254).
Ver: Leccion 09, Leccion 15B
T
TCP/IP Redes
Conjunto de protocolos que define como se transmiten datos en Internet. TCP garantiza entrega ordenada y confiable; IP maneja el direccionamiento y enrutamiento de paquetes.
Ver: Leccion 01
TLS (Transport Layer Security) Criptografia
Protocolo criptografico que proporciona comunicacion segura sobre redes (HTTPS). Usa certificados X.509, intercambio de claves y cifrado simetrico para el canal de datos.
Ver: Leccion 06
V
Volatility Forense
Framework de analisis de memoria RAM. Permite extraer procesos, conexiones de red, credenciales y artefactos de malware de un volcado de memoria.
Ver: Leccion 17
W
Wireshark Forense
Analizador de protocolos de red que captura y examina trafico en tiempo real. Permite filtrar por protocolo, IP, puerto y reconstruir sesiones completas.
Ver: Leccion 19
WPA2 Pentesting
Protocolo de seguridad WiFi. En modo PSK (clave compartida), es vulnerable a ataques de diccionario si se captura el 4-way handshake mediante deautenticacion.
Ver: Leccion 14
X
XSS (Cross-Site Scripting) Web
Vulnerabilidad que permite inyectar codigo JavaScript en paginas web vistas por otros usuarios. Tipos: Reflected (en URL), Stored (en base de datos), DOM-based (en cliente).
Ver: Leccion 09
