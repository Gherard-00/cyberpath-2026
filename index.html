Fase 0 — Cimientos Absolutos (Meses 0–3)

Aquí aprenderás todo lo que necesitas saber sobre redes, Linux y programación antes de tocar cualquier herramienta de hacking.

01

Redes y TCP/IP — Cómo se comunican las computadoras

Aprende qué es una red, cómo viajan los datos, qué son los puertos, TCP vs UDP, DNS, HTTP y cómo funciona Internet por dentro.

Teoría + Práctica ~3 horas
→ 02

Linux desde Cero — Tu sistema operativo de trabajo

Aprende a instalar Linux, manejar la terminal, archivos, permisos, procesos, y scripting en Bash. Todo con ejemplos reales explicados.

Teoría + Práctica ~4 horas
→ 03

Python para Ciberseguridad — Programación orientada a hacking

Aprende Python desde cero con enfoque en seguridad: sockets, automatización, parsing de logs y creación de herramientas.

Teoría + Práctica ~4 horas
→ 04

Montar tu Laboratorio Virtual — Tu entorno de práctica seguro

Aprende a instalar VirtualBox, configurar redes virtuales, montar Kali Linux, Metasploitable y Active Directory paso a paso.

100% Práctica ~2 horas
→

Fase 1 — Introducción a la Ciberseguridad (Meses 3–6)

Aquí aprenderás los conceptos fundamentales de seguridad informática, criptografía y darás tus primeros pasos en hacking ético.

05

Fundamentos de Seguridad Informática

Qué es la seguridad informática, la tríada CIA, tipos de amenazas, malware, ingeniería social, y cómo piensa un atacante.

Teoría ~2 horas
→ 06

Criptografía Esencial — Cómo se protege la información

Cifrado simétrico vs asimétrico, funciones hash, firmas digitales. Práctica con GPG y OpenSSL.

Teoría + Práctica ~3 horas
→ 07

Ética y Legalidad del Hacking

Qué está permitido, qué no, cómo obtener autorización, código de ética, y diferencia entre hacker ético y cibercriminal.

Teoría ~1 hora
→

Fase 2 — Pentesting Fundamental (Meses 6–18)

Aquí aprenderás a usar las herramientas reales de pentesting: cómo escanear redes, encontrar vulnerabilidades, explotarlas y reportar hallazgos.

08

Nmap — Escaneo de redes y descubrimiento de servicios

Cómo funciona un escaneo de puertos, tipos de escaneo (SYN, TCP, UDP), scripts NSE, detección de servicios y sistemas operativos.

Teoría + Práctica ~3 horas
→ 08B

Fundamentos de Desarrollo Web — Lo que necesitas antes de hackear webs

Cómo funciona una app web: HTML, JavaScript, HTTP, bases de datos SQL y el flujo completo de una petición. Prerrequisito para Web Hacking.

Teoría + Ejemplos ~2 horas
→ 09

Hacking Web — OWASP Top 10 explicado y practicado

Inyección SQL, XSS, CSRF, IDOR: qué son, cómo funcionan, cómo explotarlos y cómo defenderse. Todo con ejemplos reales.

Teoría + Práctica ~4 horas
→ 10

Burp Suite — Pentesting de aplicaciones web

Cómo interceptar peticiones HTTP, usar el Repeater para probar IDOR, usar Intruder para fuerza bruta, y analizar respuestas.

100% Práctica ~3 horas
→ 11

Metasploit — Framework de explotación de vulnerabilidades

Cómo funciona Metasploit, cómo buscar y usar exploits, payloads, Meterpreter, post-explotación y escalada de privilegios.

Teoría + Práctica ~3 horas
→ 12

Cracking de Contraseñas — Hydra, John the Ripper y Hashcat

Cómo funcionan los hashes, tipos de ataques de fuerza bruta, diccionarios, y cómo crackear contraseñas paso a paso.

Teoría + Práctica ~2 horas
→

Fase 3 — Red Team y Técnicas Avanzadas (Meses 18–36)

Aquí aprenderás a simular ataques reales: Active Directory, movimiento lateral, evasión de defensas y operaciones de Red Team.

13A

Fundamentos de Windows y Active Directory

Estructura de dominios, usuarios, grupos, GPOs, Domain Controllers y PowerShell para AD. Prerrequisito para ataques a AD.

Teoría + Práctica ~3 horas
→ 13

Active Directory — Ataques a entornos corporativos

Qué es AD, cómo funciona Kerberos, ataques como Kerberoasting, Pass-the-Hash, Golden Ticket y cómo usar BloodHound.

Teoría + Práctica ~4 horas
→ 14

Hacking WiFi — Auditoría de redes inalámbricas

Cómo funciona WPA/WPA2, captura de handshakes con Aircrack-ng, ataques de deautenticación y cracking de claves.

Teoría + Práctica ~2 horas
→ 15

Red Team — Simulación de ataques reales con MITRE ATT&CK

Cómo planificar y ejecutar un ejercicio de Red Team completo: reconocimiento, explotación, pivoteo, persistencia y reporte.

Teoría + Práctica ~4 horas
→ 15B

Cloud Security 101 — Seguridad en AWS, Azure y GCP

Modelo de responsabilidad compartida, IAM, buckets expuestos, SSRF al metadata service y herramientas de auditoría cloud.

Teoría + Práctica ~3 horas
→

Fase 4 — Informática Forense y DFIR (En paralelo)

Aquí aprenderás a investigar incidentes de seguridad: analizar memoria RAM, discos duros, tráfico de red y generar reportes forenses.

16

Fundamentos de Informática Forense

Qué es la forense digital, cadena de custodia, adquisición de evidencia, integridad con hashes y el proceso forense completo.

Teoría ~2 horas
→ 17

Volatility 3 — Análisis forense de memoria RAM

Cómo capturar RAM, analizar procesos, detectar rootkits, inyecciones de código, conexiones de red y extraer malware.

Teoría + Práctica ~4 horas
→ 18

Autopsy — Análisis forense de discos duros

Cómo crear un caso forense, cargar imágenes de disco, buscar archivos borrados, construir timelines y generar reportes.

Teoría + Práctica ~3 horas
→ 19

Wireshark — Análisis de tráfico de red y detección de amenazas

Cómo capturar paquetes, usar filtros de visualización, detectar escaneos, fugas de datos y reconstruir conversaciones.

Teoría + Práctica ~3 horas
→

Fase 5 — Profesionalización y Nivel Experto (3+ años)

Aquí aprenderás a escribir informes profesionales, prepararte para certificaciones y desarrollar tu mentalidad de experto.

20

Elaboración de Informes Profesionales de Auditoría

Cómo escribir un resumen ejecutivo, documentar hallazgos con CVSS, crear fichas técnicas y redactar guías de remediación.

Teoría + Plantillas ~3 horas
